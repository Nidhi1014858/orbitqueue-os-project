## 1. Project Overview

**OrbitQueue** is an end-to-end Linux simulation of satellite downlink packet scheduling for a small satellite ground-station link (modeled after the SomaiyaSat and SomaiyaPod nanosatellite missions, `KJS-SRS-01`). When contact windows and electrical power are constrained, three distinct streams compete for radio transmission:
1. **TT&C / Housekeeping:** Critical telemetry, tracking, and telecommand data (guaranteed transmission headroom; never deferred or rejected).
2. **SSTV (Slow Scan TV):** Large image frames (deferrable payload).
3. **Voice / Data:** Digital voice and general scientific measurements.

Four core Operating Systems experiments are integrated into a single unified architecture:
- **Experiment 7 (Process Synchronization):** Bounded priority queue (`PacketQueue`) using POSIX mutexes and semaphores (`empty`, `full`, `bulk`) to reserve critical slots, plus Reader-Writer telemetry synchronization.
- **Experiment 8 (Memory Management):** Two-level address translation simulating paging (100-byte page frames) and segmentation (Code, Model Params, Input Buffer, Output Log, Stack) with bounds violation checks.
- **Experiment 9 (Deadlock Avoidance):** Banker's Algorithm safety checking before granting simulated CPU slots, buffer units, and RF transmitter allocations.
- **Experiment 10 (Virtual Memory):** Evaluation of FIFO, LRU, and Optimal page replacement algorithms over deterministic memory traces generated by the downlink router.

The formal architectural diagram is documented in [`docs/architecture.mmd`](docs/architecture.mmd).

## 4. Linux Setup and Execution

The project is designed and tested on Ubuntu Linux (Ubuntu 22.04 LTS / 26.04 VM or WSL 2).

### Prerequisites (Ubuntu / Debian)
```bash
sudo apt update && sudo apt install -y build-essential python3 python3-pip git
pip3 install -r ml/requirements.txt
```

### Build Commands
```bash
# Clean and compile all binaries into build/
make clean && make

# Build ThreadSanitizer binary for runtime race detection
make tsan

# Run self-tests across memory and synchronization modules
make test
```

### Running the End-to-End Pipeline
Always run automation scripts using `bash <script>`:
```bash
# 1. Environment audit (records OS, kernel, compiler, and hardware concurrency)
bash scripts/env_check.sh

# 2. Run complete end-to-end pipeline (data gen -> ML -> router -> Bankers -> memory)
bash scripts/run_all.sh

# 3. Comprehensive performance and resource measurement
bash scripts/measure.sh
```

## 5. Experiment Execution Commands

Each experiment can be executed independently or as part of the integrated pipeline:

### Experiment 7: Synchronization & Concurrency (`satellite_sync`)
```bash
# Safe synchronized Producer-Consumer execution (audits depth, critical slots, no drops)
./build/satellite_sync --demo=pc --mode=safe | tee outputs/exp7_safe.txt

# Unsafe execution demonstrating race conditions and packet loss (200,000 iterations)
./build/satellite_sync --demo=pc --mode=unsafe --iterations 200000 | tee outputs/exp7_unsafe.txt

# Reader-Writer telemetry demonstration (reader preference, no torn reads)
./build/satellite_sync --demo=rw --mode=safe | tee outputs/exp7_readerwriter.txt

# ThreadSanitizer race detection audit
./build/satellite_sync_tsan --demo=pc --mode=safe
./build/satellite_sync_tsan --demo=pc --mode=unsafe
```

### Integrated Router Application (`router_app`)
```bash
# Run integrated router linking ML decisions, Exp 7 queue, Exp 9 resources, and Exp 8/10 trace
./build/router_app --csv data/satellite_data.csv --decisions outputs/decisions.csv --workers 2
```

### Experiment 8: Paging & Segmentation Translation (`memory_management`)
```bash
# Run self-test verifying page tables, segment limits, and violation handling
./build/memory_management --selftest

# Run address translation suite over test input
./build/memory_management --test data/addr_tests.txt
```

### Experiment 9: Banker's Deadlock Avoidance (`bankers`)
```bash
# Run all pre-configured task scenarios (safe sequences and unsafe rollbacks)
./build/bankers --scenario all | tee outputs/exp9_scenarios.txt

# Run internal algorithm self-test
./build/bankers --selftest
```

### Experiment 10: Page Replacement Analysis (`page_replacement`)
```bash
# Compare FIFO, LRU, and Optimal algorithms across frame allocations (1, 3, 4, 5)
./build/page_replacement --ref-file data/page_trace_sample.txt --frames 1,3,4,5

# Evaluate algorithms on the real trace produced by router_app
./build/page_replacement --ref-file outputs/page_trace.txt --frames 3,4,5
```
